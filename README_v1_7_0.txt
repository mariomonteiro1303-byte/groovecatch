GrooveCatch Web v1.7.0 - Central Multimídia (primeira entrega)
Conversor local de áudio: MP3, WAV e FLAC. Entradas: MP3/WAV/FLAC/M4A/AAC/OGG/OPUS. Limite 100 MB. Requer FFmpeg disponível no PATH.
Instalação: execute instalar_e_iniciar.bat no Windows.
Nota: a conversão ocorre no computador que executa o servidor Flask. Não publicar este endpoint sem autenticação, limites de recursos e proteção adicional.
